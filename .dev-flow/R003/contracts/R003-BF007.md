## Implementation Scope

### Goal

Forward Python MCP meta tool selector parameters to the App debug plane using
`X-DCP-*` headers, converge stale page tool calls after page capability
gone/expired responses, and keep Bearer auth/device error semantics unchanged.

### In Scope

- Modify `python/debug_control_plane/mcp_plane/bridge_client.py`.
- Modify `python/debug_control_plane/mcp_plane/server.py`.
- Update `python/tests/test_bridge_client.py` and `python/tests/test_server.py`.
- Add a small selector header helper that can emit:
  `X-DCP-Capability-Id`, `X-DCP-Capability-Scope`, `X-DCP-Page-Id`, and
  `X-DCP-Scope-Revision`.
- Extend `BridgeClient.invoke()` with optional selector inputs, and merge
  selector headers with existing `Authorization: Bearer ...` headers.
- Extend `BridgeClient.read()` to pass the same selector inputs through the
  GET path.
- Make `invoke_command` and `read_resource` consume BF006 schema parameters
  `scope`, `page_id`, and `scope_revision`.
- Validate selector arguments before forwarding: `scope` is `app|page`;
  `scope_revision` is a real integer; page-scoped calls require `page_id`.
- Check the local `CapabilityMirror.schemas(device_id)` snapshot before
  forwarding explicit page selector calls. If cache is empty or stale-looking,
  refresh once before judging.
- Return a stable MCP page stale/gone error when an explicit page selector is
  missing from the current mirror snapshot.
- When the App returns 410 `page_capability_gone` or 409
  `capability_scope_expired`, preserve the original HTTP status/body/code,
  refresh the mirror once, and best-effort emit `notifications/tools/list_changed`
  only when refresh reports changed.
- Keep `DeviceAuthError`, `DeviceStale`, `DeviceUnreachable`, non-page
  `DeviceHttpError`, and transport failures on their existing error paths.

### Out Of Scope

- Do not modify `PROTOCOL.md`, Dart, Kotlin, Flutter, Android integration, or
  fixtures.
- Do not change `protocolVersion=1`.
- Do not change BF006 `CapabilitySchema` metadata parsing or mirror diff
  semantics except as needed for snapshot lookup.
- Do not generate page identity in Python.
- Do not put `pageId/pageName` into capability ids, route paths, MCP tool names,
  or device ids.
- Do not add runtime dependencies.
- Do not change Bearer token storage, clearing, authorization bootstrap, or auth
  header names.
- Do not blindly retry old page calls after gone/expired; refresh the mirror and
  let the caller list/select current tools again.
