# R003-BF007 Implementer Evidence

## Implementation Summary

- `BridgeClient.invoke/read` now accept optional selector arguments and forward
  them as `X-DCP-*` headers without replacing `Authorization`.
- `McpServer` meta handlers parse selector args, reject stale explicit page
  selectors against the local mirror snapshot, and preserve legacy dispatch
  when selector args are absent.
- App `page_capability_gone` and `capability_scope_expired` responses are
  preserved as HTTP errors while triggering best-effort mirror refresh and
  `tools/list_changed` when the refreshed manifest changed.
- BF007 server responsibilities are split into private helpers so
  `invoke_command/read_resource` stay thin.
