## Implementation Summary

- Added Dart auth protocol mirror in `dart/lib/src/debug_auth.dart`, including route classification, Bearer parsing, auth decisions, auth route results, denial helpers, and `DebugAuthManager`.
- Extended `RouteRequest` with default empty `headers` so existing transports and tests remain source-compatible.
- Updated `ControlPlane` to gate `/hello`, `/state`, direct `/events`, and capability GET/POST routes when auth is enabled, while preserving bare mode when `authManager == null`.
- Added system-priority `POST /auth/request`, `/auth/status`, and `/auth/claim` routes.
- Updated `HttpSseTransport` to propagate request headers and run `/events` preflight before SSE headers, subscriber registration, or `: connected`.
- Exported the Dart auth API through `dart/lib/debug_control_plane.dart`.
