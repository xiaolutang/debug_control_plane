## Implementation Result

Added ControlPlane auth route integration:

- `ControlPlane` now accepts optional `authManager`; `null` preserves existing bare debug-plane behavior.
- `RouteRequest` now carries `headers` with a default empty map, preserving existing call-site compatibility.
- `HttpSseTransport` forwards NanoHTTPD request headers into `RouteRequest` for normal dispatch routes.
- `GET /hello` returns minimal auth bootstrap when auth is enabled and Bearer authorization is denied; authorized or auth-disabled hello keeps the full payload.
- Sensitive dispatch routes short-circuit on `DebugAuthDecision.Denied` before `/state` aggregation or capability handlers execute.
- `POST /auth/request`, `/auth/status`, and `/auth/claim` are system bootstrap routes with priority over capability routes.
- `DebugAuthManager` now has bootstrap route extension points for request/status/claim.
