## Implementation Result

Added SSE pre-hijack auth for the production Kotlin HTTP transport:

- `HttpSseTransport` now has a volatile `/events` preflight hook and calls it before `hijackEvents()`.
- `GET /events` preflight constructs a `RouteRequest` with method, segments, headers, and the NanoHTTPD request handle before any SSE subscriber is created.
- `ControlPlane` configures the transport preflight at start time using the same optional `DebugAuthManager` used by normal sensitive routes.
- `ControlPlaneServer.create(...)` accepts optional `authManager` and passes it to `ControlPlane`; existing call sites remain source-compatible through the default `null`.
- Auth denied responses reuse `RouteResult.error(...)`, preserving `{ok:false, code, message}` JSON and status code behavior.
- Auth disabled and authorized branches keep existing SSE headers, byte-exact `: connected\n\n` first frame, subscriber lifecycle, and broadcast frame format.
