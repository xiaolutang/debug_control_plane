# R002-FF003 Evidence

## Implementation

- 新增 `flutter_debug_control_plane/example/lib/src/acceptance_plane_host.dart`：
  - abstract `PlaneHost`（最小接口，contract 选项 a）：`start`/`stop`/`capabilityCount`/`setOnRequestLog`（pending 通知与日志单入口）/`approvePending`/`denyPending`/`tokenPresent`/`clearToken`/`canExpireToken`/`expireToken`；无 wire 协议类型泄漏。
  - `DartPlaneHost implements PlaneHost`：薄适配器，纯委托现有 `AcceptancePlane`（BF006 wire 协议不外泄），FB001 行为零回归。
- 新增 `flutter_debug_control_plane/example/lib/src/android_native_plane.dart`：
  - `AndroidNativePlane implements PlaneHost`：包装 `NativeControlPlaneBridge`（构造注入 channel），`start()` = attach + `bridge.start(address: 0.0.0.0, port: 0)` + 逐个注册 `buildCapabilities()` 的 4 个 capability（每次注册新建 `BridgeCapability` 包装，规避 D2 单订阅）。
  - pending 回调（native `auth.request` methodcall）→ 合成 `AcceptanceRequestLogEntry`（route=`/auth/request`、statusCode=202、authResult=`pending`、requestId/clientLabel）经唯一 sink 进 controller；controller `_applyLog` 照常驱动 pending 弹窗（复用 5 标识）。
  - `approvePending` → `bridge.approveAuthorization`，成功 claim 后合成 `claimed`（200）条目并置 `tokenPresent=true`；`denyPending` → `bridge.denyAuthorization` + `denied`（403）；`clearToken` → `bridge.revokeAuthorization(all: true)` + `cleared` 条目 + `tokenPresent=false`（Q3）。
  - `canExpireToken=false`（PluginDebugAuth 无 TTL 注入 API，Q3 协商决策）；`expireToken()` 抛 UnsupportedError（UI 层按钮已禁用不可达）。
  - stop 后到达的 pending 回调丢弃（contract 异常路径）。
  - capability HTTP 日志：native 反向 invoke Dart handler，handler 内 `recordCapabilityLog` 经 plane 的 authManager sink 中继到同一 sink —— 单一日志入口（state_consistency）。
- 修改 `acceptance_controller.dart`：持有 `PlaneHost`；`AcceptanceController()` 默认 DartPlaneHost，`AcceptanceController.withHost()` 注入 native host。六态状态机、`_applyLog` 单源逻辑不变；`clearToken`/`expireToken` 经 host（Dart 行为不变）；新增 `canExpireToken` 只读视图。controller 内无 mode 分支。
- 修改 `main.dart`：仅新增 `createAcceptanceController()`（`Platform.isAndroid` → native 模式，DEC-R002-005），`_AcceptanceHomeHost` 使用之；`expire_token_button` 的 `onPressed` 与 `_ControlButton` 支持 nullable（状态同源：disabled ⇔ `canExpireToken==false` ⇔ `onPressed==null`）。12 个稳定标识与 AuthDialog 接线零改动。
