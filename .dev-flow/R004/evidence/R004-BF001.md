# R004-BF001 Implementer Evidence

## Implementation Summary

- 新增 `FileTokenProvider`（`DebugAuthTokenProvider` Protocol 的首个正式实现）：
  懒加载（`_loaded` 首次 get/save/clear 触发读盘）、asyncio 单线程假设（docstring
  声明，不加锁）、save/clear 后全量落盘。
- 0600 保证：tmp 文件以 `os.open(O_WRONLY|O_CREAT|O_TRUNC, 0o600)` 创建绕过
  umask（无 0644 窗口），写入 + fsync 后 `os.replace` 原子替换；异常时清理 tmp。
- expiresAt 判定：`datetime.fromisoformat(value.replace("Z", "+00:00"))`
  （py310 兼容）；解析失败/naive → 视为未过期；读时判定、不回写。
- 损坏（OSError/ValueError）或 version != 1 → 静默回退空 store，server 不崩。
- schema：`{"version": 1, "tokens": {device_id: {token, tokenId, expiresAt}}}`，
  metadata 仅存 str 值（非 str 转字符串）；与 devices.json 完全独立，未 import
  device_pool。
- `server.py` main() 注入：`BridgeClient(pool=pool, token_provider=FileTokenProvider())`
  （仅加一行注入 + import，未改其他逻辑）。
